## 清洗规则

| 规则 | 判定 |
|---|---|
| 重复行 | 与前面某行完全相同，只保留首条 |
| 缺失值 | `CustomerID` 或 `Description` 缺失 |
| 取消订单 | `InvoiceNo` 以字母 C 开头（大小写不敏感） |
| 非正数数量 | `Quantity <= 0` |
| 非正数价格 | `UnitPrice <= 0` |

各规则独立统计（允许同一行命中多类）；清洗时命中任意一类即移除。
